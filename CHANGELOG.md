# Changelog

All notable changes to Relato will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/).

## [0.1.0] — 2026-04-13

### Added
- Visual UML class diagram builder with drag-and-drop nodes and edges
- Four relationship types: Association, Dependency, Inheritance, Aggregation
- Properties panel for editing class names, fields, methods, and edge properties
- Edge color, width, and curvature customization via context menus
- Dark/Light theme switching with OKLCH color space
- Auto-layout via ELK (top-to-bottom and left-to-right)
- Design Patterns Library (GoF patterns: Memento, Observer, Strategy, Factory Method, Singleton, Adapter)
- PNG/JSON diagram export with viewport-aware cropping
- Full undo/redo history for all diagram changes (dragging, editing, layout, connections)
- Context menus for quick node and edge actions
- Explanation cards with numbered callouts and anchor connections
- Keyboard shortcuts for power users (N, L, Del, Ctrl+Z, etc.)
- Bottom toolbar with layout, zoom, and export controls
- Left sidebar with pattern library
- LocalStorage persistence for auto-save/restore
- Responsive canvas with pan, zoom, and fit-view
